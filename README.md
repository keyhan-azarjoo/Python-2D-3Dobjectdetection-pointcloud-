# 2D & 3D Object Detection on Point-Cloud / LiDAR Data

A deep-learning pipeline for 2D and 3D object detection, semantic segmentation, and digital-twin
generation from LiDAR point-cloud data.

## Methods
- **3D deep learning** — PointNet for point-cloud segmentation and classification
- **2D detection** — CNN and YOLO-family models
- **LiDAR spatial processing** → semantic segmentation → digital-twin generation
